# Security

Please report security problems privately. Don't open a public issue.

Use GitHub's **Report a vulnerability** button on this repository's Security
tab (private vulnerability reporting).

Include what you found, how to reproduce it and what it affects. We'll
acknowledge your report and keep you updated while we fix it.

In scope: anything in this repository that could make an agent spend a
user's credits without their approval, leak a credential or project data, or
run code on a user's machine. Problems in Radiate's hosted service are also
welcome through the same channels.

This package holds no credentials and runs no code; it describes how agents
should call Radiate's hosted MCP server. Never send us your API keys or
tokens.
